# Modelos didáticos DreamBuild PC

Originais procedurais gerados em Blender 5.2.3 LTS pelo script `blender_scripts/generate_pc_parts.py`, em 30/10/2026. CPU AM5, GPU com três ventoinhas, kit DDR5 e gabinete com frente ventilada. Aproximadamente 0,5 a 0,7 MB por GLB, sem texturas remotas.

São ilustrações para estudo; não são modelos oficiais, digitalizações nem reproduções dimensionais dos produtos. O gabinete contém peças internas meramente ilustrativas. O arquivo `blender_scripts/pc_parts_reference.blend` guarda uma cena por modelo para edição e aprendizado. As fotografias dos fabricantes permanecem a apresentação principal da loja.
